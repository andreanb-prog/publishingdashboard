# AuthorDash: AI systems for indie authors

Marketing site for Andrea's one-on-one consulting: helping authors build Claude, ChatGPT and other AI systems for the business side of publishing.

All copy (sessions, prices, FAQ, booking link) lives in `lib/site.ts`.

```bash
npm install
npm run dev
```

The original AuthorDash dashboard app is preserved in git history on `main` before this branch.
